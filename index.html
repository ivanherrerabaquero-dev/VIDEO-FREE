Escenas

Cada escena va de «desde» a «hasta» en segundos. En «detalles» van sus opciones (personaje, hora del cielo, ángulos del dron…).

Qué opciones tiene cada tipo
  • titulo: auto de perfil con artista y canción. hora: [0.3, 0.4]
  • auto: auto de perfil con el paisaje pasando. hora
  • dron: tomas siguiendo al auto. angulos: ["cenital","persecucion","lateral"], cada (segundos por toma), hora
  • carretera: carretera de frente con personaje. personaje, lado, fantasma, hora
  • recuerdo: luz dorada. personaje, objeto
  • cierre: noche, auto detenido y créditos. personaje
  • foto: imagen con zoom. imagen, zoom: [1.05, 1.18]
  • video: clip a pantalla completa. archivo, inicioClip

«hora» va de 0 (tarde) a 1 (noche): [inicio, fin] de la escena.

Cualquier escena acepta "filtro": "byn" (blanco y negro, para recuerdos), "calido" o "frio".

Letra

Una línea de la canción por renglón.

«Sincronizar con toques»: suena la canción y marcas cada palabra con la barra espaciadora (o tocando el botón) justo cuando se canta.

Voz

Carga tu voz cantada, ojalá sola y sin pista. El estudio detecta las notas, tu rango, la tonalidad y las frases, y usa esa información en el video.

Medios

Prepara un personaje: carga una imagen con fondo liso y el estudio se lo quita. Luego la descargas o la subes al repo.

GitHub

Para guardar desde el portal necesitas un token personal de GitHub con permiso Contents: Read and write solo sobre este repo. El token queda guardado únicamente en este navegador.

Cómo crear el token
  1. En GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → VIDEO-FREE.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Copia el token y pégalo aquí.
